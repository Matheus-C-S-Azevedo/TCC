\chapter{HIPÓTESE}
É possível desenvolver de uma solução de \textit{software} em linguagem c para suporte à implementação de asset administration shell embarcados aplicados à industria 4.0. O desenvolvimento de uma solução de \textit{software} nativa em linguagem C, projetada desde a sua concepção para sistemas com recursos limitados, é capaz de viabilizar a implementação de um AAS em ambientes embarcados de forma eficiente.
